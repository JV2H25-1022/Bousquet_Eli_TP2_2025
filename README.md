## Contexte

Travail pratique réalisé en 2025 dans le cadre de ma formation en Technique d’intégration multimédia (Cégep Édouard-Montpetit). **Projet individuel.**

## Objectifs

- Explorer la création d’une expérience de jeu vidéo indépendant de bout en bout
- Concevoir des systèmes de gameplay cohérents
- Intégrer des animations 3D fluides
- Produire une ambiance sonore qui renforce l’identité visuelle du jeu

## Technologies

Unity · C# · Blender (modélisation, rigging, animation) · Adobe Premiere Pro (montage de la vidéo de présentation)

## Instructions d’exécution

1. Installer [Unity Hub](https://unity.com/download) et la version **Unity X.X.X** (à confirmer : *Project Settings → ou fichier `ProjectSettings/ProjectVersion.txt`*).
2. Cloner le dépôt :
   ```bash
   git clone https://github.com/jaajness/jeu-video-unity.git
   ```
3. Dans Unity Hub : **Add → Add project from disk**, puis choisir le dossier cloné.
4. Ouvrir la scène `Assets/Scenes/NOM_DE_LA_SCENE.unity` et appuyer sur **Play**.
5. Contrôles : *(à compléter — ex. WASD pour se déplacer, souris pour regarder, Échap pour le menu)*

> Pour une version jouable sans Unity, télécharge la build dans la section [Releases](https://github.com/jaajness/jeu-video-unity/releases) *(à ajouter si disponible)*.

## Démarche

1. **Conception & prototype** — concept, mécaniques principales et boucles de gameplay, prototype jouable pour valider les sensations
2. **Architecture des systèmes** — personnage, physique et progression en C#, avec un code modulaire et réutilisable
3. **Animation & assets 3D** — modélisation et rigging dans Blender, intégration via l’Animator Controller d’Unity
4. **Audio & VFX** — bande sonore, effets sonores et effets visuels, polish global
5. **Tests & livraison** — tests fonctionnels, correction de bugs, optimisation et build finale

## Résultats

- Build jouable complète et stable
- Systèmes de gameplay documentés et réutilisables
- Pipeline d’animation Blender → Unity établi
